1. ЧТО ЭТО ЗА ПРОЕКТ
--------------------
FluxLane (fluxlane-platform) — локальная веб-платформа для:

  • обзора KPI и графиков (ДТП, нарушения, эвакуация, 2024–2026);
  • оперативного мониторинга и ленты уведомлений;
  • карты дорожных событий (ДТП из базы);
  • карты и маршрутов (19 датчиков D1–D19, треки, OSRM-маршруты);
  • админ-панели и импорта Excel.

Стек: Node.js + Express + SQLite + Socket.IO; фронт — HTML/CSS/JS,
Leaflet (карты), Chart.js (графики).

7. КАРТА И МАРШРУТЫ (traffic-analysis.html)
-------------------------------------------
Датчики:
  • В базе 19 датчиков D1–D19 (координаты в Смоленске).
  • Отображаются синими маркерами при загрузке страницы.

Построение маршрута A → B:
  1) Раскройте блок «Маршрут A → B» на панели справа.
  2) Нажмите «Точки на карте».
  3) Кликните на карте точку A, затем точку B.
  4) Нажмите «Найти маршрут».

Логика:
  • Сначала маршрут строится по дорожной сети OSM (OSRM) между выбранными
    координатами — работает между любыми точками в городе.
  • Если OSRM недоступен, используется запасной путь по графу датчиков
    (/api/traffic/shortest-path).

Левая панель:
  • Тёмная карточка с точками A/B, расстоянием, временем в пути,
    кнопкой «Очистить маршрут».

Подложка карты:
  • OpenStreetMap, без API-ключа.
  • Карта ограничена областью Смоленска (нельзя «уехать» далеко от города).

Потоки на карте:
  • Укажите интервал дат/времени → «Показать» — линии треков по рёбрам.

10. API (ОСНОВНОЕ)
------------------
Префикс: http://localhost:3000/api/

ДТП и события:
  GET /accidents/statistics?year=2025
  GET /accidents/map-events?from=2024-01-01&to=2024-12-31

Штрафы / эвакуация:
  GET /fines/statistics?year=2025
  (аналогичные маршруты для evacuations)

Трафик:
  GET  /traffic/detectors
  GET  /traffic/edges
  GET  /traffic/roads
  GET  /traffic/shortest-path?fromDetectorId=1&toDetectorId=5&weightType=distance
  GET  /traffic/route?fromLat=54.78&fromLon=32.04&toLat=54.79&toLon=32.05
  POST /traffic/edges/build?force=0   — построение геометрий рёбер через OSRM
  POST /traffic/import-detectors      — импорт (multipart, админка)
  POST /traffic/import-passages

Переменные окружения:
  PORT=3000
  GRAPHHOPPER_URL=http://...   — опционально, вместо OSRM

13. УСТРАНЕНИЕ НЕПОЛАДОК
------------------------
Сервер не запускается:
  • Занят порт 3000 — закройте другой процесс или задайте PORT=3001.
  • npm install в папке проекта.
  • Проверьте, что node доступен: node -v

Страница белая / API 404:
  • Запущен ли npm start?
  • URL должен быть http://localhost:3000/...

Карта без тайлов:
  • Проверьте интернет и блокировку tile.openstreetmap.org.
  • F12 → Console — ошибки Leaflet.

Маршрут не строится:
  • Выбраны ли обе точки A и B?
  • Доступен ли OSRM (интернет); смотрите Network → /api/traffic/route.

После сброса БД:
  npm run init-db
  npm run seed-accidents
